# Diccionarios ampliados

`words-es-extended.txt` y `words-en-extended.txt` son selecciones de 49 271 términos en español y 46 504 en inglés, ordenados por frecuencia, del proyecto [FrequencyWords](https://github.com/hermitdave/FrequencyWords), mantenido por hermitdave y derivado de OpenSubtitles 2018. Las listas originales incluyen el número de apariciones; para este mod se filtraron las primeras 50 000 entradas de cada idioma a palabras alfabéticas Unicode de 3 a 20 letras, sin duplicados ni contadores. Esas listas de contenido se distribuyen bajo [Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Se mantienen separadas del código del mod.

Los diccionarios pequeños `words-es.txt` y `words-en.txt` se pueden editar en la carpeta de configuración para dar prioridad a las palabras del servidor. Los términos ampliados se cargan como respaldo incluso si ya existe una configuración antigua.
